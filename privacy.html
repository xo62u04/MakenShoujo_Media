資料蒐集範圍

魔劍少女 MakenShouju 是由獨立開發者製作的遊戲專案。我們的社群帳號主要用於分享開發進度，本專案不主動蒐集訪客的個人資料。

當您透過社群帳號與我們互動時，以下資料可能由 Meta 平台自動蒐集（並非由本專案直接蒐集）：

  • 您的公開個人資料（姓名、大頭照）——當您按讚或留言時
  • 您的 IP 位址及瀏覽器資訊——由 Meta 平台伺服器紀錄
  • 您與貼文的互動行為（按讚、分享、留言）

上述資料的蒐集與使用，均受 Meta 隱私政策管轄，與本開發者無關。

2

資料使用方式

我們僅將您在社群平台上的互動資料用於以下目的：

  • 了解開發內容對受眾的吸引力，以改善未來的開發日誌
  • 回覆您在貼文下的留言或私訊
  • 分析貼文觸及率以優化內容策略

我們不會將您的個人資料出售、租賃或以任何形式提供給第三方廣告商。

3

第三方服務

本專案的社群自動發文工具整合了以下官方服務，並受其各自服務條款與隱私政策約束：

  • Meta Graph API / Facebook — 用於在粉絲專頁發布貼文
  • Threads API — 用於在 Threads 帳號發布貼文
  • Discord Webhook — 用於開發者內部草稿預覽（不對外公開）

若您對 Meta 平台如何處理您的資料有疑問，請參閱 Meta 隱私政策。

4

資料儲存與安全

所有用於操作社群帳號的 API 金鑰（Access Token）均儲存在開發者本地端設備，並透過環境變數管理，不會上傳至任何公開儲存庫或第三方伺服器。

發布過的貼文記錄以 JSON 格式儲存於本地端，僅供開發者自行參考，不對外提供存取。

我們採取合理的技術措施保護帳號安全，但請理解，任何網際網路傳輸方式都無法保證 100% 的安全性。

5

您的權利

在適用法律範圍內，您有權：

  • 要求查閱我們持有的您的個人資料
  • 要求更正不正確的個人資料
  • 要求刪除您的個人資料
  • 撤回您對資料處理的同意

如需行使上述任何權利，請透過下方聯絡方式與我們聯繫。我們將盡力在合理時間內回覆您的請求。

6

Cookie 使用

本 GitHub Pages 靜態網站本身不使用任何 Cookie 或追蹤技術。

若您透過連結前往 Meta 旗下的 Facebook 或 Threads 平台，這些平台可能會使用 Cookie。相關規範請參閱各平台的 Cookie 政策。

7

我們保留隨時修訂本隱私政策的權利。若政策有重大變更，我們將在本頁面更新「最後更新」日期。

建議您定期查閱本頁面以了解最新政策。繼續使用我們的社群帳號，即表示您接受更新後的政策。
